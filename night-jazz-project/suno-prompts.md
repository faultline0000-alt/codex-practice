# Suno 프롬프트 20개

## 사용법
1. Custom 모드 ON + Instrumental ON
2. Title / Style of Music / Lyrics 칸에 아래 내용 붙여넣기
3. Exclude Styles: `vocals, singing, heavy drums, distorted, EDM, fast tempo`
4. 첫 곡이 마음에 들면 Persona로 저장 → 나머지 곡에 적용해 음색 통일
5. 짧으면 Extend로 3~4분까지 연장 / 템포가 빠르면 Style에 `slow tempo, laid back` 추가

## Lyrics 칸 (공통)
```
[Intro: soft solo piano]
[Verse: main melody, gentle]
[Chorus: full trio, warm]
[Instrumental Break: soft solo]
[Verse: melody returns]
[Outro: slow fade, piano alone]
[End]
```

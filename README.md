## 투자 복리수익 계산기 · 차곡차곡

HTML, CSS, JavaScript만으로 만든 한글 계산기입니다. 외부 라이브러리, API, 서버, 패키지 설치가 필요 없습니다.

### 실행 방법

1. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP**을 선택했다면 압축을 풉니다.
2. `index.html`을 크롬, 엣지, 사파리, 파이어폭스 등의 최신 브라우저에서 엽니다.
3. 초기 투자금액, 연 수익률, 투자기간을 입력하고 **미래 자산 계산하기**를 누릅니다. Enter 키로도 계산할 수 있습니다.

### 파일 구성

- `index.html`: 입력 폼, 계산 결과, 연도별 표
- `style.css`: PC와 모바일 화면에 맞춘 디자인
- `script.js`: 입력 검증, 복리 계산, 금액 표시
- `README.md`: 실행 및 테스트 안내

### 계산 방식과 입력 범위

연도별 평가금액 = 초기 투자금액 × (1 + 연 수익률 ÷ 100)^연도

총 투자수익 = 최종 평가금액 − 초기 투자금액

- 초기 투자금액: 1원 ~ 1조 원 사이 정수. `1000000`, `1,000,000` 모두 가능합니다.
- 연 수익률: -100% ~ 100%. 소수와 음수를 허용하며, `%` 기호는 입력하지 않습니다.
- 투자기간: 1 ~ 100년 사이 정수.
- 결과가 JavaScript의 안전한 정수 범위(9,007,199,254,740,991원)를 초과하면 오류를 표시합니다.
- 연 1회 복리로 계산하며 중간값은 반올림하지 않습니다. 화면의 금액만 원 단위로 반올림하고 천 단위 쉼표를 표시합니다. 이 때문에 표시 금액 간 차이가 1원 발생할 수 있습니다.
- 추가 납입, 세금, 수수료, 물가 변동은 제외합니다. 수익률은 매년 일정하다고 가정하며 실제 수익을 보장하지 않습니다.

### 브라우저에서 테스트하기

각 값을 입력한 뒤 계산 버튼을 누르고 다음 결과를 확인하세요.

| 초기 투자금액 | 연 수익률 | 투자기간 | 예상 결과 |
| --- | --- | --- | --- |
| 1,000,000 | 10 | 2 | 최종 1,210,000원, 수익 210,000원. 표: 시작 1,000,000원 → 1년 1,100,000원 → 2년 1,210,000원 |
| 1,000,000 | 0 | 3 | 최종 1,000,000원, 수익 0원 |
| 1,000,000 | -10 | 2 | 최종 810,000원, 수익 -190,000원 |
| 1,000,000 | -100 | 1 | 최종 0원, 수익 -1,000,000원 |
| 1000000 | 5.5 | 1 | 최종 1,055,000원, 수익 55,000원 |
| 빈 값, 문자, 0원, 음수 투자금, `1,00` | 7 | 10 | 오류 안내, 이전 결과 제거 |
| 1,000,000 | -101 또는 101 | 10 | 오류 안내 |
| 1,000,000 | 7 | 0, 101 또는 1.5 | 오류 안내 |
| 1,000,000,000,000 | 100 | 100 | 계산 범위 초과 안내 |

브라우저 창을 모바일 크기(너비 375px 정도)로 줄여 입력창과 결과가 한 열로 배치되는지도 확인하세요. 표는 필요한 경우 가로로 스크롤할 수 있습니다. Tab 키로 입력창과 버튼을 이동하고 Enter 키로 계산해 보세요. 브라우저 개발자 도구의 Console에 오류가 없는지도 확인할 수 있습니다.
